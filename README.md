# IAI? — Site institucional

Site institucional da IAI? — Marketing, design e tecnologia para o comércio local.

## Publicação com GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

O ponto de entrada é `index.html`. O site é estático e não exige instalação de dependências.

## Configurar o WhatsApp

Edite `config.js` e informe o número comercial em formato internacional, somente dígitos: código do país + DDD + telefone (por exemplo, `5582999999999`, fictício).

Enquanto o número estiver vazio, o formulário prepara e permite copiar a mensagem, mas não mostra um link de WhatsApp.
